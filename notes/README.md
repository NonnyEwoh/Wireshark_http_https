# Working notes

Use this folder for non-sensitive notes about troubleshooting, command output summaries, and lessons learned.

Suggested topics:
- Differences between the handout and your VM.
- Interface name used and why.
- Wireshark display filters that worked.
- Version differences or unexpected packet details.
- Questions to revisit.

Do not store credentials, session cookies, tokens, personal information, or raw packet payloads here.
