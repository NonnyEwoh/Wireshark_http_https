# Packet captures

Raw packet captures are intentionally excluded from this public portfolio. They can contain credentials, cookies, personal information, and unrelated traffic.

Keep files such as `httpdump.pcap` and `httpsdump.pcap` locally in the authorized lab environment. The repository `.gitignore` excludes common capture extensions, and the GitHub Actions workflow checks that none have been committed.

If a course instructor requires capture files, follow the course's approved private submission process. Do not upload captures to a public GitHub repository.
